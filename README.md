# 💼 Salary Prediction using Linear Regression

## 📌 Project Description

This project implements a **Salary Prediction system** using **Linear Regression**.
The model predicts an employee’s **expected salary based on years of experience**.

The project includes:

* Data analysis and model training using Python
* A trained machine learning model
* A **Streamlit web application** for real-time salary prediction

This project is created as a **mini project** for academic learning and practical understanding of machine learning concepts.

---

## 📁 Dataset Information

* **Dataset Name:** Salary Dataset
* **File:** `Salary_dataset.csv`

The dataset contains:

* Years of Experience
* Corresponding Salary values

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Selvaganapathy-k/salary_prediction-linear-regression-
cd salary_prediction-linear-regression-
```

---

### 2️⃣ (Optional) Create Virtual Environment

```bash
python -m venv venv
```

Activate the environment:

**Windows**

```bash
venv\Scripts\activate
```

**Linux / macOS**

```bash
source venv/bin/activate
```

---

### 3️⃣ Install Required Libraries

```bash
pip install -r requirements.txt
```

---

### 4️⃣ Run the Streamlit Application

```bash
streamlit run app.py
```

The application will open in your browser automatically.
